## Project Overview
This project analyses employee attrition to identify factors associated
with employees leaving an organisation.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL Server
- Jupyter Notebook

## Key Findings
- Sales had the highest departmental attrition rate at 20.7%.
- Human Resources had an attrition rate of 19.0%.
- Research and Development had an attrition rate of 13.8%.
- Employees working overtime had an attrition rate of 30.6%.
- Employees not working overtime had an attrition rate of 10.4%.

## Analysis
The project includes:
- Data cleaning
- Exploratory data analysis
- GroupBy analysis
- Correlation analysis
- Outlier detection
- Data visualisation
- SQL analysis
- Business recommendations
